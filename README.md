# LPC & OPC Study Companion

A phone-friendly PWA starter for LPC and OPC preparation.

## Included
- Main menu with the eight requested subjects
- Three sections per subject: Study, Additional Notes, Review
- Airframes & Flight Controls populated with the notes supplied
- Slide navigation and flashcard reveal controls
- Additional notes saved in browser local storage
- Basic offline caching

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `manifest.webmanifest`, and `sw.js` to the repository root.
3. In repository Settings → Pages, select deploy from branch and choose `main` / root.
4. Open the published URL in Safari on your iPhone.
5. Use Share → Add to Home Screen.

## Important
Notes are stored in the browser on the device. Clearing Safari website data can remove them. The other seven subjects are menu placeholders until their study material is added.
